关键设计决策清单

终端流式布局

消息全左对齐流式下排，用户消息用 ▸ 标记，AI 消息用角色名标记，不搞左右聊天气泡

工具调用卡片化

每个工具调用独立卡片：标签 + 参数摘要 + 结果。成功绿色描边，失败红色，运行中蓝色

Diff 内联展示

edit_file/write_file 直接在卡片内展示 diff，绿色底色 + 行，红色底色 - 行

Shell 终端风格

shell 输出用暗底代码块，成功/失败用不同顶部色条区分，保持终端感

Todo 内联卡片

不弹到顶部面板，直接卡片内显示进度条 + 状态图标，紧凑高效

子代理折叠卡片

task 工具结果默认折叠，显示 spinner+耗时，展开后看完整输出

权限确认为内联弹窗

不用 MessageBox 弹窗打断流，改成消息流中的内联确认块
