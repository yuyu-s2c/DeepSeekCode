# UI 全面重构 — 设计规格书

**日期**: 2026-06-07
**状态**: 已确认
**主题**: 白底天蓝终端风格 UI 重构

---

## 1. 设计目标

将当前纯色块堆砌、无层次感的深色 UI，重构为**白底 + 天蓝点缀**的 Claude Code 终端风格布局。核心原则：

- **消息不分左右** — 全左对齐流式排列，这是开发工具不是聊天软件
- **工具调用卡片化** — 每个工具调用独立卡片，状态色编码
- **动画不省** — spinner、过渡、计时器不能省略
- **信息层次分明** — 颜色语义化，弱化次要信息

## 4. 消息类型规范

### 4.1 系统消息
- 颜色: `PrimaryLight` (#88a8c0)
- 字号: 10px
- 无前缀标记

### 4.2 用户消息
- 前缀: `▸ 你` (PrimaryBlue, 10px, Bold)
- 内容: PrimaryDark (#1a2a38), 12px
- 无气泡背景，纯文本左对齐
- 右键菜单保留（复制、重新发送）

### 4.3 AI 正文消息
- 前缀: `DeepSeek` (比 PrimaryBlue 稍亮的蓝 #58a8d8, 10px, Bold)
- 内容: PrimaryDark (#1e3040), 12px
- Markdown 渲染（代码块用暗色背景）

### 4.4 AI 思考过程（可折叠）
- 卡片背景: 极浅蓝 (#f8fbfd)
- 边框: 浅蓝 (#e0ecf4)
- 标题: `▶ 思考过程` (#68a0c8, 9px)
- 内容: 浅灰蓝 (#a8c0d0), 9px
- 默认折叠，有内容时自动展开

## 5. 工具调用卡片规范

所有工具调用统一使用卡片样式，左侧 2px 色条表示状态。

### 5.1 卡片结构

```
┃ [图标 工具名]  参数摘要                    ⏱ 耗时
┃ ┌────────────────────────────────────┐
┃ │ 标题栏（可选）                      │
┃ │ 结果内容...                         │
┃ └────────────────────────────────────┘
```

### 5.2 状态色彩

| 状态 | 左边框色 | 标签背景 | 标签字色 | 耗时色 |
|------|---------|---------|---------|--------|
| 运行中 | #38a0e0 蓝 | #e8f4fc | #3098d0 | 实时跳动 |
| 成功 | #a0d0a0 绿 | #e8f8e8 | #48a048 | #58a058 |
| 失败 | #e0a0a0 红 | #fff0f0 | #c04040 | #c05050 |
| 警告 | #e0a040 橙 | #fff8e8 | #d09030 | #c08040 |
| 排队 | #c8d8e8 灰 | #f0f4f8 | #90b0c8 | — |
| 中性(读取) | #d0e4f0 浅蓝 | #e8f3fb | #3098d0 | #a0c0d0 |

### 5.3 耗时格式

| 范围 | 格式 | 颜色 |
|------|------|------|
| <1ms | `<1ms` | #88a8c0 灰 |
| 1-999ms | `12ms` | #a0c0d0 淡蓝灰 |
| 1-9s | `3.4s` | #c08040 浅橙 |
| ≥10s | `12.8s` | #c05050 浅红 |

### 5.4 各工具具体呈现

**glob** — 中性卡片，列出匹配文件路径
**grep** — 中性卡片，行号+匹配行高亮
**read_file** — 中性卡片，行号+语法着色代码
**edit_file** — 成功卡片，内联 diff（+绿底 -红底）
**write_file** — 成功卡片，内联 diff（全+行绿色）
**shell** — 暗色终端块，成功绿色顶条/失败红色顶条
**webfetch** — 中性卡片，标题+正文摘要
**git_diff** — 成功卡片，diff 展示
**git_log** — 中性卡片，commit 列表
**git_commit** — 成功卡片，提交确认信息
**read_skill** — 中性卡片，技能名称+描述
**todo_write** — 中性卡片，内联进度条+4 状态图标（✔ ⏳ ○ ✘）
**task** — 4 子状态（排队/运行中/完成/警告）

## 6. 子代理 (task) 4 种状态

### 6.1 排队中 ○
- 灰色左边框，半透明整体
- 文字: "○ 等待空闲线程..."
- 无耗时

### 6.2 运行中 ⣾
- 蓝色左边框
- 头部: spinner 动画 + 工具名 + "运行中 · X.Xs"（实时跳动）
- 内容区: 子代理实时日志流（工具调用 + 结果），最大高度 120px overflow
- 底部: "▸ AI 正在分析..." 提示

### 6.3 完成 ✔
- 绿色左边框
- 头部: ✔ + 耗时
- 内容: 子代理返回的完整结果
- 可选底部: 调用明细（glob(8ms) + read_file(2ms) + ...）

### 6.4 发现问题 ⚠
- 橙色左边框
- 头部: ⚠ + 标签 + 耗时
- 内容: 问题列表，具体问题用红色 ⚠ 标记

### 6.5 折叠汇总面板
- 可折叠卡片，显示所有子代理状态概览
- 标题: `▶ 子代理 (1 运行中, 2 完成, 1 排队)`
- 右侧: `总耗时: XXs`

## 7. 其他 UI 变化

### 7.1 权限确认 → 内联
当前用 `MessageBox.Show()` 弹窗阻断 UI。改为消息流内的内联确认块：

- 橙色左边框
- 背景: 淡黄 (#fffdf0)
- 标题: "⚠ 权限确认"
- 内容: "允许执行 shell: dotnet build 吗？"
- 按钮: [允许] (蓝) [拒绝] (灰)

### 7.2 状态栏
- 左: 模型名 · Token 数 · 缓存命中率
- 右: 本轮总耗时 · 工具调用次数
- 运行中显示: "⏳ 1 个子代理运行中"

### 7.3 停止按钮
从独立的红色底栏按钮改为浮在输入区上方的内联元素。

### 7.4 设置按钮
保留齿轮图标，位置在输入区左下角。

### 7.5 滚动词
消息流自动滚动到底部，工具卡片展开不打断阅读位置。

## 8. 动画规范

| 元素 | 动画 | 时长 |
|------|------|------|
| Spinner (⣾⣽⣻⢿⡿⣟⣯⣷) | 8 帧循环 | 120ms/帧 |
| 子代理运行中计时 | 每秒 +0.1s 跳动 | 实时 |
| 工具卡片出现 | 从上方滑入 | 200ms ease-out |
| 状态栏耗时 | 每秒更新 | 实时 |
| 输入区边框 | focus 时边框变蓝 | 150ms |

## 9. 文件改动范围

### 需修改的文件
1. **App.xaml** — 新增 ResourceDictionary，定义全部颜色 Token

3. **MainWindow.xaml.cs** — 消息渲染方法重构，工具卡片渲染，耗时追踪
4. **SettingsWindow.xaml** — 配色适配
5. **ApiKeyWindow.xaml** — 配色适配
6. **MarkdownRenderer.cs** — 颜色 Token 化
7. **DiffRenderer.cs** — 颜色适配白底
8. **SyntaxHighlighter.cs** — 确认暗色代码区颜色

### 需新增的文件
1. **Services/TimingService.cs** — 工具执行耗时追踪

## 11. 风险点

1. **FlowDocument 布局限制** — WPF FlowDocument 不支持 CSS flexbox 式布局，工具卡片需用 BlockUIContainer + Border 堆叠
2. **颜色资源替换量大** — 5 个 XAML 文件 + 3 个 CS 文件，需要逐个检查
3. **动画流畅度** — WPF DispatcherTimer 在高频更新时可能有性能问题，需实测
4. **向后兼容** — 功能行为不变，仅 UI 层变化，风险较低
